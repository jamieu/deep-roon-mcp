- Waveforms: `roon_waveform` gives the waveform of the track that plays in a zone, as Roon draws it in its seek bar — a list of heights from 0 to 1 (`points`, default 100) over the track, with the position and length. Roon makes one for a local file when it has analysed it, and since 2.74 for a Qobuz or TIDAL stream the first time it plays; until then the tool says there is none yet. Only for what plays now: Roon doesn't hand out waveforms per track to extensions. Thanks to the tester who asked
- Tip: after an update, restart your MCP client (or refresh its tool list) — a client that keeps the old tool list won't know the new tool
