- **MCP over HTTP:** `DEEP_ROON_HTTP=[host:]port` serves Deep Roon MCP as Streamable HTTP (stateless, `POST /mcp`) instead of stdio — for a client that can't start a program on your computer. The host defaults to `127.0.0.1`. There is no authentication: keep it local, or put it behind something that has one. Never expose it to the internet as it is
