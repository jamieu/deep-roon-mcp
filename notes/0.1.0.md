The first release: fifty tools for your Roon Core, from Claude Desktop, Claude Code or any MCP client.

- **Read:** search your library and Qobuz at once; Qobuz's shelves by genre; album pages with credits; the reviews and biographies Roon shows, in full; discographies; Focus on albums, tracks, artists and works with the Focus panel's counts; Daily Picks, New releases for you and the Daily Mixes; playlists, favourites and Listen Later; other versions and more like this; Roon's signal path and MUSE; your play history and real "most played" counts
- **Play:** albums, your own running order of tracks, playlists (shuffled), Daily Mixes; the buttons, seek, volume, shuffle / repeat / Roon Radio; the queue; transfer, group and ungroup zones; sleep timer and standby; the cover of what plays
- **Change, on request:** hearts, Listen Later, adding a Qobuz album to the library, new playlists, MUSE on and off — each reads the result back and says if Roon didn't follow
- `roon_status` with a self-test; "Essentials only" (17 tools) for small models; a switch for the official API alone
- Unofficial: built on Arthur Soares' work on Roon's internal protocol, which Roon Labs allows for personal use. Runs on your computer, talks only to your own Core
