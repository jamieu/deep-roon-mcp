- `roon_track_files`: the file path of your own tracks, as the Core sees it — for an album, an artist or a list of track keys, with Roon's track key, title, track number, format and any duplicates (Library::GetTrackExportInfo…, the data behind Roon's own Export). Streaming tracks have no file and are reported as such. Asked for on the Roon forum, to join Roon's tracks with data kept per file
